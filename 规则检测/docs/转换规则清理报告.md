## 已清理类型

1. **转换规则状态链 / flowbits**：`noalert`、`flowbits:set/isset` 属于跨包状态关联，
   转换规则不再注入 flowbits；相关 SID 只保留元数据；自研场景的 19 条 flowbits
   保留用于 Lua 精确判定；
2. **请求→响应依赖**：`depend/scope_id` 的转换规则不再进入 Suricata，
   `success_rules.json` 保留完整依赖关系，交 xbits 关联；
3. **转换规则行为/聚合**：`threshold`、`lua`、`tag`、`xbits` 选项不进入转换规则；
   自研场景 Lua/threshold 保留，用于签名增强与误报收敛；
4. **自研 Web Lua**：保留 SQLi/XXE/Log4Shell 等 9 条 Lua 签名增强规则；
   Zeek 侧不再重复做 Web 内容匹配；
5. **加载不兼容 SID**：Suricata `-T` 验证失败的 100 个 SID，直接隔离；
6. **空规则文件/目录**：清理后自动删除。

## 语义降级处理

语义降级**不是原始规则文件缺数据**，而是上一版转换器为了兼容 Suricata 做了
剥离/近似处理。现已按“要么补回语义、要么从规则中清除”处理：

| 原始字段/语义 | 处理方式 |
|---|---|
| `status_code:N` | 由剥离改为转换：`content:"N"; http_stat_code;`，保留状态码约束；多值/非数字直接剔除 |
| `reference` / `classtype` | 从 Suricata 规则剥离，但保留到 `rules_meta.json` / `sid_library.json`；不影响检测语义 |
| `http_only_uri` | 无 Suricata 等价语义：规则剔除，只保留元数据 |
| `rate` | 厂商限速/抑制语义无法等价转换：规则剔除，只保留元数据 |
| `rawbytes` / `resp` / `logto` / `method` | 厂商/Snort 特有语义无法等价转换：规则剔除，只保留元数据 |
| 绝对定位(offset/depth)与相对定位(within/distance)混用 | 原转换会丢弃绝对定位；现改为直接剔除规则 |
| 重复 offset/depth | 原转换会去重；现改为直接剔除规则 |
| 悬空 `http_uri`（前面不是 content） | 原转换会丢弃；现改为直接剔除规则 |
| 响应方向中的请求侧缓冲关键字 | 原转换会丢弃；现改为直接剔除规则 |

结果：

- 转换规则中不再包含 `status_code` / `http_only_uri` / `rate` /
  `rawbytes` / `method:` / `resp:` / `logto:` 等降级字段；
- 17 条 active `status_code` 规则使用 `http_stat_code` 正确约束；
- `sid_library.json` 保留 9,017 条 references、1,819 条 classtype、
  650 条 status_code、6 条 rate 元数据；
- 14,120 条无法等价转换、状态链/依赖关联或被语义安全校验拦截的规则记录于
  `xbits/规则库元数据/semantic_gaps.json`，**不进入 Suricata 规则文件**。

  语义树重写后 `dangling-http-uri` 判定已撤销（旧版误删 2,073 条正确顺序
  规则，已回流为前置 sticky buffer 形式），改为 `buffer-without-payload`
  判定（悬空 buffer 无承接匹配）。
